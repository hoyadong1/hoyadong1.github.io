육아 기록 데이터 삭제 안내

앱: 육아 기록 (Google Play, 패키지명 com.hoyadong.yeah_buddy_timer) · 개발자: hoyadong

앱은 회원가입이 없습니다. 가족 공유를 쓰지 않았다면 서버에 저장된 데이터가 없으며, 모든 기록은 휴대폰 안에만 있습니다.

방법 1. 앱에서 바로 삭제 (가족 공유를 쓴 경우)

  1. 육아 기록 앱을 엽니다.
  2. 오른쪽 위 설정(톱니바퀴) → 가족과 함께 기록을 누릅니다.
  3. 맨 아래 공유 그만하기를 누르고 확인합니다.
  4. 가족 공간에 남은 사람이 있다면, 그 사람도 같은 방법으로 공유를 그만합니다. 마지막 사람이 그만하면 서버의 아기 정보와 기록이 즉시 모두 삭제됩니다.

방법 2. 이메일로 요청

앱을 이미 삭제했거나 위 방법을 쓸 수 없다면, Google Play 스토어의 앱 상세 페이지에 있는 개발자 이메일로 "육아 기록 데이터 삭제 요청"이라고 보내 주세요. 가능하면 아기 이름(또는 태명)과 공유를 시작한 대략의 날짜를 적어 주시면 해당 가족 공간을 찾아 요청일로부터 7일 이내에 삭제하고 회신합니다.

휴대폰 안의 데이터

휴대폰에 저장된 기록은 앱을 삭제하거나 [휴대폰 설정 → 앱 → 육아 기록 → 저장공간 → 데이터 삭제]를 누르면 지워집니다.

삭제되는 데이터와 보관 기간

데이터처리
아기 이름·생일, 육아 기록(시각, 종류, 분유량, 메모 등), 호칭, 가족 구성원의 익명 ID삭제 즉시 서버에서 지워지며 별도로 보관하지 않습니다.
초대 코드발급 후 24시간이 지나면 사용할 수 없으며, 가족 공간 삭제와 함께 효력을 잃습니다.
익명 인증 기록(Firebase 익명 사용자 ID)이름·연락처가 없는 임의의 ID이며, 이메일 삭제 요청 시 함께 삭제합니다.
광고 관련 정보(광고 ID 등)Google AdMob이 처리하며 개발자가 보관하지 않습니다. 휴대폰 설정 → 개인정보 보호 → 광고에서 광고 ID를 삭제할 수 있습니다.
